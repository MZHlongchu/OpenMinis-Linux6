# Minis Ultra 1.35-linux

- versionCode **51**
- applicationId `com.openminis.linux`
- 启动器名称：**Minis Ultra**
- APK：`minis-ultra-com.openminis.linux.apk`（arm64-v8a）

## 本版摘要

相对 **1.34.1-linux**：审批可以「本会话全部允许」；提示词模板与工作区规则合并为「人格扩展」一页；工具限额并入多智能体设置页；协作角色不再写死、可自行增删改；人格字数上限彻底取消；覆盖安装也会把「从没动过」的默认人格升级为内置版本。

## 变更

### 1. 审批：本会话全部允许

审批卡片和聊天内横幅都新增第三个按钮「本会话全部允许」：

- 按下后当前请求照常放行，并且**本次会话内后续敏感操作全部自动通过**——不再弹卡片、不再发通知栏审批。
- 开关是会话级的：停止 / 中断 / 清理会话时自动复位，不会泄漏到下一个会话。
- 只影响需要「确认一次」的操作；`DENY_ALL` 模式、权威围栏拒绝、致命命令拦截依旧生效。

### 2. 提示词模板 + 工作区规则 → 人格扩展

两者本质都是 SOUL 人格的延伸，设置页里合并为**一个入口**：

- 设置 → 人格组 → **人格扩展**，页内分「会话提示词模板」和「工作区规则」两段。
- 原来的两个独立页面保留为 deep link 目标（`minis://settings/prompt-templates`、`minis://settings/workspace-rules` 仍可直达，现都落在合并页）。
- 数据格式与行为不变：模板按会话绑定、下一轮热切换；规则仍是设备上的 Markdown 文件库。

### 3. 工具限额并入多智能体

- Shell 超时、`file_read` 字符上限、`file_read` 行数上限、子代理轮次四项步进器移到**多智能体**设置页尾部。
- 设置页的「工具限额」独立入口删除；`minis://settings/tool-limits` deep link 仍可用。

### 4. 协作角色不再写死

多智能体设置页的「协作角色」区从只读目录变成可管理：

- 点自定义角色 → 编辑（角色名 / 一句话描述 / 角色提示词 / 工具白名单，逗号分隔），可删除。
- 「+ 新增角色」直接创建；自定义角色带 `*` 标记。
- 点内置角色 → 以「保存为自定义副本」方式打开（名字只读）。
- 自定义角色与内置同名时**覆盖内置**；白名单留空表示不限制工具。
- 派发时 `spawn_agent` 的 `role` 参数命中自定义角色，其提示词与工具白名单真正生效。

### 5. 人格不再限制字数

SOUL.md 原先有三处长度闸（中文 1600 字 / 英文 1000 词），现已全部移除：

- 设置页保存按钮：只要求「已加载 + 有改动」，不再因超限禁用。
- `minis-config` 写入：不再因超限拒绝（注入措辞检查仍保留）。
- 系统提示注入：不再截断，人格正文**逐字全量**注入。
- 编辑器计数器只显示字数，不再标红、不再提上限。

### 6. 默认人格对覆盖安装也生效

内置默认人格（`assets/default_soul.md`）原先只在**全新安装**时种入，老安装永远停留在最初的 4 行 starter。现在启动时做一次判定：

- SOUL.md 不存在 → 种入内置默认人格。
- SOUL.md 与内置默认一致 → 不动。
- SOUL.md 仍是**原始 4 行 starter**（说明用户从没改过）→ 升级为内置默认人格。
- 其它任何内容（用户改过一个字、`minis-config` 写过、恢复过备份）→ **永不触碰**。

判定幂等，升级后即走「一致 → 不动」分支。

---

**未变更**：数据库版本（仍为 Room 14）、SecurityGate 权限模式与规则、工具审批的通知栏入口、子代理调度与并发上限。
