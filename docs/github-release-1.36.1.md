# Minis Ultra 1.36.1-linux

- versionCode **54**
- applicationId `com.openminis.linux`
- 启动器名称：**Minis Ultra**
- APK：`minis-ultra-com.openminis.linux.apk`（arm64-v8a）

## 本版摘要

修好两件 1.36 里「看起来有、装上没用」的事：缺参数的模型真正套上 256k / 128k / 思考 max / 文本；设置里 − / 数字 / + 点中间数字可以输入，确定时按 min/max 夹紧。

## 变更

### 1. 缺参模型默认值真正生效

1.36 对名字里带 GPT / Claude / Qwen 等的 id 整段跳过默认值，中转站只回 ID、不带参数时思考开关是关的、上下文是空的。现在 **缺哪个补哪个**：

- 上下文 **256k**
- 最大输出 **128k**
- 开启思考，档位 low–max（天花板 **max**）
- 输入/输出模态 **文本**

目录、DataLearner、用户覆盖仍优先。已落库的条目不用重新拉模型列表，打开会话即按缺项补上。

### 2. 步进器点数字输入

多智能体并发上限、重试次数，以及 Shell 超时、file_read 字符/行数、子代理最大轮次：− / + 中间显示当前数字，点数字弹出输入框，确定时按各自 min/max 夹紧。总开关关掉也能改这些数字。

---

**未变更**：数据库版本（Room 14）、签名、包名。
