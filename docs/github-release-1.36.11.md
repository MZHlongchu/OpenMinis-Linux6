# OpenMinis-Linux 1.36.11-linux

- versionCode **64**
- applicationId `com.openminis.linux`
- 启动器名称：**Minis Ultra**
- GitHub：[`tall-1997/OpenMinis-Linux`](https://github.com/tall-1997/OpenMinis-Linux)
- APK：`minis-ultra-com.openminis.linux.apk`（arm64-v8a）

## 本版摘要

长会话人格不再被历史盖过；AI 过程折叠改为完成后立刻收起，折叠后仍能点开工具详情；子代理运行中可看实时日志，结束后有 Trace / Report。人格页一级去掉保存按钮，返回时自动写入身份。

## 变更

### 人格（已有会话）

1. **系统提示纠偏** — Personality 块写明：更早的回复可能是旧人设，不要跟着学。
2. **请求时绑定** — 有人格且会话已有助手回复时，只在发给模型的最近一条用户文本前加 `<persona-binding>`（不入库、界面看不到）。新会话第一句没有历史，不加这段。
3. **压缩摘要** — 注明以当前系统提示里的人格为准。

### AI 过程折叠

1. **增量收起** — 思考一结束（后面出现工具/正文）立刻收进摘要；工具跑完立刻收；只有正在跑的工具还展开（底部条也还在）。等下一轮模型输出时，已完成的过程保持收起。开关仍默认关。
2. **折叠后仍能看工具详情** — 详情页不再跟悬浮条共用「只含进行中工具」的列表。折叠态摘要上有可点子芯片。

### 子代理

1. **运行中可点** — 顶栏芯片打开实时详情，步骤日志会刷新。
2. **批量直播** — 多个 `spawn_agent` 也会把各子代理日志写进工具块。
3. **结束后更细** — 输出拆成 `## Trace`（工具时间线 + 参数/结果摘要）和 `## Report`。

### 人格设置页

1. **提示词** — 切换即保存（不变）。
2. **名称 / 风格 / 图标、恢复默认** — 返回时自动保存；一级页去掉保存按钮。
3. **二级编辑页** — 仍保留保存，改正文才需要明确提交。

## 兼容性

- 数据库仍为 Room 16，无迁移。
- 签名、包名不变。侧载覆盖安装即可。可与官方 OpenMinis 并排安装。已装 1.36.10（versionCode 63）会被 64 覆盖。
