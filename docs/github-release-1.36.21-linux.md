# 1.36.21-linux

versionCode **74**。安装包 `minis-ultra-com.openminis.linux.apk`。

相对 1.36.20-linux：

## 输入与会话

- 打开已有会话不再弹出键盘。
- 只有这次访问里确实流式回复过、且没有手动滚走，结束后才重新聚焦输入框。

## 人格提示词

- 内容相同（名称不同，或名称内容都相同）会问「该提示词文件与××文件内容一致，是否导入」。确认后另存一份，不覆盖。
- 名称相同、内容不同会问「该提示词文件与××文件名称一致，是否覆盖」。确认才覆盖私有文件；取消则改名另存。
- 内置 SOUL.md 不能删除，也不能被覆盖。
- 下拉列表里，私有提示词旁边可以删除，只删 `minis-global/memory/personas` 里的文件。

## 子代理

- 每个子代理一张对话卡片、一枚芯片，不再互相盖住。
- 卡片和详情只显示当前步骤，不回放整段历史。
- 芯片显示协作角色和子代理类型。
- 结束或停止后芯片消失。
- 单个子代理抛出的 Error 不再取消同一批里的其它子代理。

## 稳定性

- 点工具卡片或大段内容时，不再把当前界面送回桌面。
- `execute_code` 在 Android 上不再因缺少 `javax.lang.model.SourceVersion` 崩溃。桩的 `latestSupported()` 固定为 `RELEASE_8`，避免加载依赖 `java.lang.Module` 的实现。
- 保留 `org.json` 类名，避免和系统自带的 JSON 实现冲突。

## 沙箱自编译

- 设置里的实验性自编译不再在没编译时也报告成功。
- 失败会显示在该设置项上，而不是让界面崩溃。
- 只有挂载树里存在 `scripts/build_apk_aarch64.sh` 时，才会先安装 SDK 再编译。
